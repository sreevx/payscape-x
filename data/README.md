# PAYSCAPE-X data directory

Organized synthetic data used to develop and test PAYSCAPE-X.

- `scenarios/` — declarative failure/injection scenarios (e.g. provider
  outage, inventory shortfall). Consumed by the Simulation Engine in Part 3.
- `samples/` — sample structured event batches and journey fixtures used by
  tests and by the synthetic event pipeline in Part 2.

Nothing in this directory is production data.
